Understanding the OSI Model

The OSI model is a conceptual framework for understanding how data travels across networks. Each layer has a specific role in communication between connected systems.

The Seven OSI Layers

07

Application

Provides network services to applications.

06

Presentation

Represents, encodes, and transforms data.

05

Session

Coordinates sessions between applications.

04

Transport

Supports end-to-end data transport.

03

Network

Handles logical addressing and routing.

02

Data Link

Handles frames and communication between adjacent nodes.

01

Physical

Transmits raw bits through physical media.
