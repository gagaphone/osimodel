# OSI Model Layers and Protocols

## About the Project

The **OSI Model Layers and Protocols** website is an educational reference guide to the seven layers of the Open Systems Interconnection (OSI) model. It explains the purpose of each layer and provides a quick reference to commonly associated network protocols and technologies.

## Built With

- **HTML5** — Website structure and content
- **CSS3** — Responsive layout and styling
- **JavaScript** — Interactive protocol table, live search, and layer filters

## Features

- Overview of all seven OSI layers
- Searchable protocol and technology reference table
- Filter protocols by OSI layer
- Responsive design for desktop and mobile devices
- Simple, accessible interface for networking learners

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Search the protocol table or select an OSI layer to explore the reference.

No additional software, dependencies, or build tools are required.

## Deployment

This website can be published for free using **GitHub Pages**.

1. Upload the project files to your GitHub repository.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and the `/(root)` folder, then click **Save**.
5. Open the published website using the URL provided by GitHub Pages.

## Purpose

This project aims to make networking concepts easier to understand and provides a convenient reference for students, developers, IT professionals, and networking beginners.
